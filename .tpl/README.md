# SRIGEN 001 模板

首读 template.json、project.json，再读 docs/ARCHITECTURE.md、CUSTOMIZATION.md、VERIFICATION.md、LICENSE.md。

五页业务与 404 双语响应式限量鞋履首发网站。准备 Node 24.16.0 与 pnpm 9.15.4，运行 `pnpm install --frozen-lockfile`、`pnpm dev`。默认 http://localhost:3000，Ctrl+C 停止。修改入口和验收见根 README。

表单仅本地校验；不发送邮件、不保存数据、不提供购买。没有数据库、支付与外部服务环境配置。阅读不会触发执行、安装、Git 或上传。使用和修改由接收方用户决定。
